# A8 – Gears

## Objective

The Objective of this project is to create a gearbox system.

## Analyze

Design of the Shafts:

The first step in the design process was to analyze the input and output shafts, by making sure that the diameter was sufficient. I did this by using the equations found in the Machinery's handbook and from the lecture to calculate the stress on both shafts. These interim values were them calculated against the maximum values needed to measure sufficiency.

Design of Journal Bearings:

The next step of this design process was to calculate the values for the journal bearings. The maximum velocity, pressure, and PV value to be able to determine the best material to use. 
(Based on these calculations, I chose bronze bearings since it had a PV of about 40,000)
